# PHANTOM X Launcher v2

Launcher حقيقي لأندرويد (Capacitor) يحافظ على رسومات التصميم الأصلي (الفهد الأسود) مع عناصر حية فوقها.

## ما الذي يعمل فعلاً
- **الساعة والتاريخ** حيّان؛ لمس الساعة يفتح المنبّهات، والتقويم يفتح تطبيق التقويم.
- **الطقس** حيّ عبر Open-Meteo (بدون مفتاح)، مع تغيير المدينة من الإعدادات وحفظ آخر قراءة للعمل دون إنترنت.
- **البطارية** حقيقية (نسبة، شحن، وقت الشحن المتبقي؛ وقت التفريغ تقديري).
- **المهام**: إضافة، تحديد، حذف بالضغط المطول، حفظ دائم، شريط تقدم.
- **العبارة اليومية** قابلة للتعديل.
- **البحث**: اكتب ثم Enter أو اضغط G؛ الميكروفون للبحث الصوتي.
- **التطبيقات**: أيقونات حقيقية من جهازك، تُكتشف تلقائياً (الكاميرا، المعرض، المتجر، YouTube، الإعدادات، الهاتف، الرسائل، المتصفح، جهات الاتصال). اضغط مطولاً على أيقونة لتغييرها.
- **درج التطبيقات** (زر البصمة أو «التطبيقات»): بحث، ضغط مطول للمعلومات أو إلغاء التثبيت، وتحديث تلقائي عند التثبيت/الحذف.
- **الأدوات السريعة**: تنظيف ← إدارة التخزين، تسريع ← تحسين البطارية، الخصوصية ← إعدادات الخصوصية، تبريد ← توفير الطاقة. (أندرويد لا يسمح لأي تطبيق بتنظيف/تبريد الجهاز بنفسه، فهي اختصارات إلى إعدادات النظام.)
- **الشريط السفلي**: الهاتف، الرسائل، الموسيقى، الدرج، وزر اللوتس لإعدادات PHANTOM X.
- **الشاشة الرئيسية الافتراضية**: تظهر نافذة عند أول تشغيل، أو من زر اللوتس ← «اجعله الشاشة الرئيسية» (RoleManager على أندرويد 10+، وإعدادات النظام على الأقدم).

## البناء على GitHub (بدون Android Studio)
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد إلى الفرع `main`.
2. من تبويب **Actions** شغّل **Build Android APK** (يعمل تلقائياً مع كل push).
3. بعد النجاح نزّل artifact باسم `phantom-x-launcher-apk` ثم ثبّت الـ APK على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).
4. للإصدار الرسمي: `git tag v2.0.0 && git push --tags` فيُرفق الـ APK بصفحة Releases.

## البناء محلياً
```bash
npm install && npm run build
npx cap add android
# انسخ AndroidManifest.xml و styles.xml وملفات Java من مجلد android/ إلى المشروع الناتج (كما في workflow)
npx cap sync android && npx cap open android
```

## حدود معروفة
- الـ APK موقّع بمفتاح debug (للتجربة الشخصية). للنشر على Google Play أضف مفتاح release، وصلاحية `QUERY_ALL_PACKAGES` تخضع لمراجعة Google.
- شارة الرسائل غير المقروءة (12) في الصورة لا تُحسب بعد (تتطلب إذن الإشعارات).
- الصورة تُمدد لتملأ الشاشة؛ مواضع العناصر محسوبة على نسبة 841×1870 وقد تنحرف قليلاً على شاشات مختلفة النسبة. عدّل الإحداثيات في `index.html` (`data-box`) و`main.js` عند الحاجة.
